# Data Dictionary

_Generated by `python -m analytics.reporting.data_dictionary` from the live PostgreSQL catalog (columns, types, row counts) and the dbt project's YAML (descriptions, grain). Raw-layer columns follow the official MIMIC-IV schema; see [config/sources.yaml](../config/sources.yaml)._

Layers: `raw` (source, typed) → `staging` (views: rename/type/flag) → `intermediate` (business logic) → `marts` (star schema) → `reporting` (aggregate views). `reference` holds dbt seeds.
